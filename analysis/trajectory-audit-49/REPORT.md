The audit supports **48 reported task trajectories** and leaves **P43 provisional** because the connection between its unsigned timed report and its signed technical page lacks a decisive schedule bridge. These verdicts describe the evidence for the reconstructed task histories; they are not authenticated agent counts.

The review follows the requested precision-first policy: an uncertain assignment remains unassigned, and an incompatible own-task claim is not explained away through speculative multiple-task assignment. No live explorer data or concurrent candidate-enumeration outputs were changed.

## The rules to use with candidate enumeration

The complete policy is in [RULES.md](RULES.md), with stable R01–R14 identifiers and a [machine-readable version](rules.json).

1. Use editor names for retrieval only. Require a body-level speaker and a substantive task bridge before assigning ownership.
2. Compare the speaker's own task, round progression, activation/due times and timer tier. Classify each clock as self or peer, and each event as prompt, answer, deadline, prediction or correction.
3. Reject inherited text as a fresh message. Split an old paragraph from a newly appended paragraph even when they share one line.
4. Keep genuine cross-posts as separate publication records. Their repeated wording does not create independent identity evidence.
5. Treat incompatible own tasks as negative evidence. A different destination page is not itself a task conflict.
6. Leave weak links unresolved. A matching signature, generic answer, same date suffix, common country sequence, or scratch-page name does not suffice by itself.

## Validation and limits

Three parallel reviewers covered disjoint partitions of the 49; the coordinating review checked cross-case editor collisions, all 39 exclusions, and consistency of the final rules. A second reviewer independently checked the seven nontrivial exclusion exceptions. The assembler verifies complete 49/49 coverage, one decision per frozen message, every evidentiary quotation as an exact original-body substring, source line references, partial-span integrity and unchanged input hashes. All archive file checksums pass. The original archive's byte-preserving Latin-1 representation is retained.

This is a retrospective internal-consistency audit, not an estimate of false-positive or false-negative rates. There is no authenticated process/run ground truth to calibrate such rates. Repeated text and multiple reviewers do not create independent underlying observations. Claims about successful answers, API activity, survival, termination or hidden harness behavior remain claims unless separately corroborated. Candidate discovery outside the frozen snapshot was deliberately left to the concurrent enumeration work.
